Project Development

Financial Compass is an educational website developed by Tendayi Gabriel Mazvomba for the BYU–Idaho WDD231 Web Frontend Development course.

The website is designed to help young adults develop financial literacy through practical lessons, interactive calculators, and personal goal-setting tools.

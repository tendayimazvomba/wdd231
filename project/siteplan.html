Financial Compass

Website Project Site Plan

Site Name

Financial Compass

The name Financial Compass represents the idea of helping people find direction when making financial decisions. Just as a compass helps someone navigate toward a destination, Financial Compass helps users navigate budgeting, saving, banking, credit, and financial goal setting.

Optional domain: financialcompass.org

Site Purpose

Financial Compass is a personal finance education website designed to help young adults develop better money-management habits.

The website will provide practical information about budgeting, saving, banking, credit management, and financial goal setting. It will also provide interactive financial tools and learning resources that help users make informed financial decisions.

Scenarios

The following questions represent information needs of visitors to Financial Compass:

  • How can I create a realistic monthly budget based on my income and expenses?
  • How much should I save each month to reach a specific financial goal?
  • Where can I find simple information about budgeting, saving, banking, and credit?
  • Which financial resources are suitable for someone beginning to learn about personal finance?

Typography

Roboto - Headings and Navigation

Roboto will be used for main headings, section titles, navigation links, buttons, and other important interface elements. Its modern appearance provides a clear visual hierarchy throughout Financial Compass.

Financial Compass - Heading Example

Roboto Medium (500) will be used for navigation links and buttons.

Roboto Bold (700) will be used for headings and section titles.

Open Sans - Body Content

Open Sans will be used for paragraphs, descriptions, financial learning resources, form labels, and other general body content. It was selected for its readability across desktop, tablet, and mobile devices.

Financial Compass helps young adults understand budgeting, saving, banking, and credit management through accessible financial education and interactive tools.

Open Sans Regular (400) will be used for general body text, while Open Sans Semi-Bold (600) will emphasize important information.
